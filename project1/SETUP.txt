
CSC 4710 - Database Web Application
Project Setup Instructions

1. Install XAMPP and Node.js.

2. Open the XAMPP Control Panel.
   Start Apache and MySQL.

3. Open phpMyAdmin:
   http://localhost/phpmyadmin

4. Open sql.txt and execute the database creation
   and CREATE TABLE statements in phpMyAdmin.
   Do not execute the parameterized queries
   containing ? placeholders directly.

5. Open the project1 folder in VS Code.

6. Open a terminal and navigate to Backend:
   cd Backend

7. Install dependencies:
   npm install

8. Create a .env file inside Backend with:

   PORT=5050
   DB_USER=root
   PASSWORD=
   DATABASE=web_app
   DB_PORT=3306
   HOST=localhost

   Update the settings for your local environment.

9. Start the backend:
   npm start

   The server should run on port 5050.

10. Open Frontend/index.html in a web browser.

11. Use the application to:
    - Register a new user
    - Log in with an existing account
    - Search users using eight search functions

12. The eight search functions are:
    - Search by first name or last name
    - Search by username
    - Search by salary range
    - Search by age range
    - Find users registered after John
    - Find users who have never signed in
    - Find users registered on the same day as John
    - Find users registered today

Notes:
- Passwords are hashed using bcrypt.
- The password database column is password_hash.
- Successful login updates signintime.
- Database queries use parameterized SQL.
- The frontend connects to http://localhost:5050.
- Searches involving John use the username john
  as the reference account, as required by the assignment.
- Register a user with username john before testing
  the "Registered After John" and "Same Day as John" searches.
- Register additional users before and after John
  to demonstrate the search results.
- Never commit the .env file to GitHub.
